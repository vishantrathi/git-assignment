# Git and GitHub Practical Assignment

This repository demonstrates core and advanced Git & GitHub workflows, including:
- Local repository initialization, staging, and unstaging (`git restore --staged`, `git reset`)
- Remote repository synchronization (`push`, `pull`, `fetch`, `merge`)
- Branching workflows, pull requests, and manual merge conflict resolution
- Reset operations (`--soft`, `--mixed`, `--hard`) and interactive hunk staging (`git add -p`)
- Repository forking and cross-repository pull requests
- Stashing with conflict resolution, `git rm`, and `git revert`
